主要功能

「蓬蓬」是您的全方位 Discord 助理

🌐

智能翻譯

使用 /tr 指令，自動偵測語言並翻譯，支援指定語言對。

🏳️

國旗表情翻譯

對訊息按下 🇹🇼 🇯🇵 🇺🇸 等國旗表情，蓬蓬就會立刻為您翻譯。

💱

即時匯率轉換

使用 /cc 指令查詢匯率，支援全球貨幣，內建快取加速。

📈

股票與加密貨幣

使用 /stock 查詢台股、美股和加密貨幣的即時價格與走勢。

🌤️

天氣預報

使用 /weather 查詢全球天氣，支援多語言城市名稱搜尋。

✈️

旅遊助手

使用 /travel 獲取城市的完整旅遊資訊，包含天氣、匯率與景點。

🏁

國旗問答

使用 /flagquiz 開始多人國旗猜謎遊戲，測試您的地理知識！

📅

每日單字

自動每日推送外語單字到指定頻道，輕鬆學習新語言。

🎲

骰子與隨機選擇

使用 /roll 擲骰子、/pick 從選項中隨機選擇，趣味互動！

更多功能持續開發中！
