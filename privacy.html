我們收集的資料

為提供核心功能，PongPong Bot 會收集以下有限的資料：

資料類型 用途 保留方式
Discord 使用者 ID 指令路由、翻譯歷史歸屬 本地資料庫
Discord 伺服器 ID 伺服器設定（語言、每日推播頻道） 本地資料庫
翻譯歷史 提供 /history 指令查詢 本地 SQLite 資料庫
Spotify OAuth Token Spotify Connect 驗證 僅暫存於記憶體，斷線即清除
指令使用紀錄 功能運作與錯誤診斷 伺服器日誌（定期清除）
✅ 我們不會永久儲存您的訊息內容。翻譯功能僅即時處理文字，不會保留原始訊息。
⚙️

資料使用方式

我們收集的資料僅用於以下目的：

  • ✅ 提供機器人核心功能（翻譯、天氣、匯率、股票等）
  • ✅ 改善服務品質與使用者體驗
  • ✅ 診斷技術問題與錯誤
  • ✅ 維護服務安全性
🚫 我們絕不會將您的資料用於廣告投放，也絕不會出售給任何第三方。
🗄️

資料儲存與保留

  • 翻譯歷史儲存於伺服器上的本地 SQLite 資料庫中
  • Spotify OAuth Token 僅暫存於伺服器記憶體，使用者斷線後立即清除
  • 伺服器託管於 Oracle Cloud Infrastructure (OCI)，位於日本東京區域
  • 資料僅在提供功能所需的時間內保留
  • 使用者可隨時要求刪除與其相關的所有資料
🔗

第三方服務

本機器人使用以下第三方服務。當您使用相關功能時，您的資料可能會依其隱私權政策被處理：

  • 🌐 Google Cloud Translation API — 翻譯文字會被傳送至 Google 伺服器處理
  • 🎵 Spotify Web API — OAuth 授權會與 Spotify 伺服器通訊
  • 🌤️ OpenWeatherMap API — 查詢城市名稱會被傳送至其伺服器
  • 💱 ExchangeRate-API — 匯率查詢不涉及個人資料
  • 📈 Alpha Vantage API — 股票查詢不涉及個人資料

我們建議您閱讀這些第三方服務各自的隱私權政策。

🛡️

資料安全

我們採取以下措施保護您的資料：

  • 🔐 所有資料傳輸使用 HTTPS 加密
  • 📉 遵循最小化收集原則 — 只收集提供功能所必需的資料
  • 🔑 伺服器存取權限僅限機器人開發者
  • 🔄 定期進行安全性更新與維護
  • 🗑️ Spotify Token 等敏感資料不會寫入磁碟
👤

使用者權利

您對自己的資料擁有以下權利：

  • 📋 有權了解我們儲存了哪些與您相關的資料
  • 🗑️ 有權要求刪除所有與您相關的資料
  • 📤 有權要求匯出您的資料
  • ⏱️ 資料刪除請求將於 30 天內處理
📬 如需行使上述權利，請透過 Email (a34159@gmail.com) 或 Discord 支援伺服器聯繫我們。
🍪

Cookie 政策

PongPong 網站本身不使用追蹤型 Cookie。

我們僅使用瀏覽器的 LocalStorage 儲存您的語言偏好設定（中文/英文/日文），以改善瀏覽體驗。此資料完全儲存在您的裝置上，不會傳送至任何伺服器。

🧒

未成年人保護

本機器人不針對 13 歲以下的兒童提供服務。我們不會刻意收集兒童的個人資料。

若我們得知有 13 歲以下的使用者使用了本機器人，我們將立即採取措施刪除其相關資料。如果您認為有兒童正在使用本機器人，請聯繫我們。

📢

我們可能會不定期更新本隱私權政策。重大更新將透過以下方式通知：

  • 📣 Discord 支援伺服器公告

在政策更新後繼續使用本機器人，即表示您接受更新後的隱私權政策。
