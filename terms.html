服務說明

PongPong（以下簡稱「本機器人」）是一款運行於 Discord 平台的多功能機器人，由開發者 Hijiri 獨立開發與維護。

本機器人提供以下功能，但不限於：

  • 🌐 智能翻譯（支援 100+ 種語言、國旗表情符號快速翻譯）
  • 💱 即時匯率兌換查詢
  • 📈 股票與加密貨幣報價
  • 🌤️ 全球天氣預報
  • ✈️ 旅遊城市資訊
  • 🏁 國旗問答遊戲
  • 📅 每日單字推播
  • 🎵 Spotify Connect 音樂串流（需 Spotify Premium）
✅

  • ❌ 不得將本機器人用於任何違法目的

年齡限制

依據 Discord 服務條款，您必須年滿 13 歲（或您所在國家/地區規定的最低年齡）才能使用 Discord 及本機器人。

若我們發現未滿最低年齡的使用者正在使用本機器人，我們會立即刪除其相關資料。

第三方服務

本機器人使用以下第三方 API 提供服務。使用本機器人的相關功能時，您同時受該第三方服務條款的約束：

  • Google Cloud Translation API — 翻譯功能
  • Spotify Web API — 音樂串流功能
  • ExchangeRate-API — 匯率查詢
  • OpenWeatherMap API — 天氣預報
  • Alpha Vantage API — 股票報價

本機器人不對第三方服務的資料準確性、可用性或安全性負責。
